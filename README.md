# AI Ethics Podcast Resources

A crowdsourced hub for our podcast on **Technology & Social Justice**, focused on the AI ethics space: algorithmic fairness, bias auditing, and the real-world impact of automated decision-making.

## What This Is

This repository collects:
- **Open-source projects** advancing algorithmic fairness and bias auditing
- **Hot debates** among researchers, practitioners, and communities
- **Discussion prompts** for listeners and contributors to share their views
- **Research materials** for anyone exploring this space

Everything here is open to contributions. To add a project, debate, or resource:
1. Fork this repo
2. Add your resource to `RESOURCES.md` or `DEBATES.md`
3. Open a pull request with a short description of what you're contributing

## Why This Matters

AI systems are making decisions about freedom, employment, healthcare, and welfare. The tools we audit — and the frameworks we use to judge them — shape who is served and who is harmed. This podcast space is for examining both.

## Navigate This Repo

| File | What's in it |
|---|---|
| `RESOURCES.md` | Active open-source projects in algorithmic fairness and bias auditing |
| `DEBATES.md` | Real unresolved controversies from the AI fairness community |
| `Issues` | Discussion prompts for listeners and contributors |

## How to Contribute

1. **Compile a resource** — Found a project, paper, or tool that belongs here? Add it to `RESOURCES.md`
2. **Spot a debate** — See an open thread in a fairness repo that deserves deeper examination? File an issue
3. **Record or transcribe** — Audio, notes, and episode drafts welcome
4. **Summarize** — Found a rich discussion? Write it up for `DEBATES.md`
